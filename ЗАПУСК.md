```

**2) battle**
```
Роль: battle
SSOT: docs/FULL-SPEC.md
Скилл: docs/skills/battle.md

**Не запускать** clan/farm агентов до soft launch.

## 3. Запуск приложения (когда появятся репо)

Появится после Phase 1–3. Целевые команды (заготовки):

| Сервис | Команда (план) |
|---|---|
| battle-service | `cd battle && go run ./cmd/server` |
| Nakama | `docker compose up nakama` |
| Unity client | открыть `client/` в Unity Hub → Play |
| LiveOps | JSON из `liveops/`, отдать CDN/локальный `http://localhost:8090` |

Пока репозиториев кода нет — этот блок не выполнять.

Скрипт-напоминалка:

```bash
./scripts/print-next.sh
```
