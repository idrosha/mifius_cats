# PvE Monster Heroes (MF-152)

Full-body **transparent** monster cutouts for Mythmir / yard live fight (`D-037`).
Not used on lobby, load, or non-fight forms.

## Roles → FX

Monsters inherit the same Web Audio + CSS kits as cat heroes by combat role
(`battle-fx.js`): idle-breathe, elemental aura, hit/block/heal floats.

| Role | Cutout pool | Soft-launch use |
|---|---|---|
| tank | tank-a…d | grass dummy tanks |
| fighter | fighter-a…h | grass dummy fighters / pitboss |
| support | support-a…c | grass dummy supports |
| assassin / ranger / mage | smaller pools | ready when stages use those roles |

## Assets

`client/web-hud/public/stitch-assets/monsters/battle/` + `manifest.json`.
