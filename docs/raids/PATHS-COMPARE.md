# Сравнение путей (рейды 1–3)

| Параметр | Короткий | Длинный |
|---|---|---|
| Время до босса | 11–14 мин | 17–22 мин |
| Килл (цель) | 8–10 мин | 6–8 мин |
| Итого до лута | ≤22 мин | ≤30 мин |
| Подготовка | почти нет | баффы / снятые усиления |
| Сложность босса | Hard | Normal |
| Лут треша | низкий | высокий + path-only |
| Босс-редметы | общий пул | общий + path-only |
| Пик координации | на боссе | на сплит-узлах (+ проще босс) |

**Trade-off:** время/нервы на треше ↔ стаки и окна на боссе.

**Когда выбирается путь:** не в лобби. Общий входной отряд (`*_a`) → победа → на той же форме боя пати голосует short/long (большинство).

Если оптимальный путь всегда один — дизайн FAIL (см. `qa/RAID_ACCEPTANCE.md`).
