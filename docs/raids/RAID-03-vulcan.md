# Рейд 3 — Пепельный Трон Девяти Хвостов

## A) Тема и лор
Вулканический дворец Кицунэ-котов. Каждый хвост — ложная личность. **Кицунэ-Император Вулкан** меняет личины. Короткий путь через Зеркальный Коридор усиливает путаницу; длинный сжигает восемь хвостов заранее.

## B) Организация
Старт: **2×6** фаланги. На ключевых узлах/боссе: **3×4** — Огонь / Дым / Зеркало.
| Группа | Задача |
|---|---|
| Огонь (4) | soak лавы, сжигание хвостов |
| Дым (4) | кик/пурдж иллюзий, марки |
| Зеркало (4) | DPS по истинной копии |

## C) Карта путей
```
[Вход: Пепельные Врата]
         |
    [A: Двор Углей]  — 2×6
         |
    ★ РАЗВИЛКА 1
    /                      \

  короткий                 сплит по хвостам
         \                      /
          [D: Мост Магмы]
                   |
            ★ РАЗВИЛКА 2
            /                      \
    [E: Прямой Трон]         [F: Хвосты V–VIII]
      Путаница×2                 личины сняты

```

| Маршрут | До пулла | Босс |
|---|---|---|
| Короткий | ~12–14 мин | Hard: 9 личин, Путаница×2 |
| Длинный | ~18–21 мин | Normal: 1 форма |

## D) Короткий — потери
8 иллюзий в Ф2; метки мешаются каждые 15с; нет Пепельного Зрения.

## E) Длинный — плюсы
Пепельное Зрение; мало иллюзий; Пепел Личины с хвостов.

## F) Узлы
| Узел | Механика |
|---|---|
| A | Лавовые волны L/R; фаланги соакают |
| B | Зеркала-дубли; накладывает Путаницу |
| C | Сплит; 4 хвоста / таймер 90с |
| D | 3 soak-платформы |
| E | Мини-кицунэ → быстрый пулл |
| F | Хвосты V–VIII |

## G) Босс — 3 фазы
1. **100–70%** Двойная Грива: 2 фаланги; 2 соак-круга по 4. Wipe: оба круга пустые.
2. **70–40%** Личины: копии = несожжённые хвосты. Wipe: 3× неверная копия.
3. **40–0%** Трон: 3×4 сектора; shared HP Сердце Вулкана. Wipe: взрыв Сердца.

## H) Лут
Обычный: пепельный сет, Угли Хвоста.  
Редметы: Пепельный Хвост; Зеркало Личин; Корона Пепла; Пепел Восьми Личин (полный клир); first-clear «Носитель Девятого».

## I) Вход / lock
Ключ Уголь Императора (weekly крафт/мировой ивент). Weekly lock лута. Эскалация +10% урона за wipe после 4-го (кап +40%).
