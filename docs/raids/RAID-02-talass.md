# Рейд 2 — Бездна Шепчущих Усов

## A) Тема и лор
Затопленный храм Глубинных Рысей. Шёпот усов тянет вниз. **Левиафан-Рысь Таласс** дремлет в разломе. Можно нырнуть сразу (давление убийственно) или стабилизировать шлюзы/маяки.

## B) Организация (4×3 — экипажи)
| Экипаж | Роль |
|---|---|
| Альфа | танк-звено босса / крупных аддов |
| Бета | контроль, интерапты, марки |
| Гамма | soak / кислородные зоны |
| Дельта | клир волн + кнопки шлюзов |

## C) Карта путей
```
[Вход: Шлюз Прибоя]
         |
    [A: Коридор Утонувших]
         |
    ★ РАЗВИЛКА 1
    /                    \
[B: Прямой Разлом]     [C: Машинный Зал Шлюзов]
  короткий               4 кнопки = 4 экипажа
         \                    /
          [D: Площадь Усов]
                   |
            ★ РАЗВИЛКА 2
            /                    \
    [E: Скат к Трону]      [F: Три Маяка + Клетка]
      Давление×2               снятие Прилива Ярости
            \                    /
```

| Маршрут | До пулла | Босс |
|---|---|---|
| Короткий B→E | ~11–13 мин | Hard |
| Длинный C→F | ~17–20 мин | Normal |

## D) Короткий — потери
Нет Баллонов (окна дыхания −40%); Прилив Ярости (4 соака/30с); Герольд в Ф3.

## E) Длинный — плюсы
Баллоны; Прилив снят (2 соака); Подсветка Слабых Точек (+15% крит окна).

## F) Узлы
| Узел | Механика |
|---|---|
| A | 2 якоря-канала против течения |
| B | DPS check shared HP Мембрана |
| C | Сплит 4×3; синхрон кнопок 1.5с или затопление |
| D | Add waves + Шёпот (Бета диспел/кик) |
| E | Стаки Глубины на босса |
| F | 3 маяка + килл Герольда |

## G) Босс — 3 фазы
1. **100–65%** Четыре Течения: 4 водоворота / экипаж; soak Игл. Wipe: пустой водоворот 5с.
2. **65–30%** Без кислорода: 4 (или 2) пузыря; кик Крика Глубин. Wipe: 6+ с Удушьем×3.
3. **30–0%** Разлом: shared HP щупальца ×4 зоны. Wipe: каст Схлопывание.

## H) Лут
Обычный: глубинная броня, Жемчуг Усов.  
Редметы: Жабры Бездны; Якорь Прилива; Коготь Разлома; Осколок Маяка (длинный); first-clear «Слышавший Шёпот».

## I) Вход / lock
Шлюз Прибоя (разовый ключ-квест). 1 weekly босс-сундук. Soft: 5 wipe → лок 30 мин.
