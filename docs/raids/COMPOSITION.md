# Рейд 12 — состав и построение (LOCKED)

Канон от продакта (2026-11-22). SoT для лобби / валидации / доски легиона.

## Таймер хода

**Ровно 60 секунд** на ход в рейде (`BATTLE_TURN_TIMER_SEC = 60` / LiveOps `limits.battle_turn_sec`).  
PvE и PvP — отдельно **30 секунд** (`BATTLE_TURN_TIMER_PVE_PVP_SEC`). По истечении — авто «Конец хода».

## Состав легиона (12 котиков)

| Роль | Кол-во | Подроли |
|------|--------|---------|
| **Танк** | **3** | 2× агр (taunt/щит) · 1× пробитие брони (pierce / fragile) |
| **Саппорт** | **3** | 2× хил · 1× баффер (ATK/щит союзникам) |
| **DPS** | **6** | остальные: маги / лучники / убийцы / воины |

Итого: **3 / 3 / 6**. Старт рейда блокируется, если танков `<3` или саппортов `<3`.

### Рекомендуемая раскладка DPS (6)

| Подтип | Кол-во | Слот строя |
|--------|--------|------------|
| Mage или Ranger | 3 | ряд дальников |
| Assassin или Fighter (воин) | 3 | ряд мили |

## Построение на доске (от тыла к фронту)

Игрок смотрит на врага впереди. Ряды союзников:

```
[ ТЫЛ    ]  ряд 3 — 3 саппорта          (2 хила + 1 баффер)
[ ДАЛЬ   ]  ряд 2 — 3 DPS дальних       (маги / лучники)
[ МИЛИ   ]  ряд 1 — 3 DPS ближних       (убийцы / воины)
[ ФРОНТ  ]  ряд 0 — 3 танка             (2 агр + 1 пробитие брони)
                 → к врагу
```

Сетка: **4 ряда × 3 колонки = 12**.

| Ряд (lane group) | Кто | Зачем |
|------------------|-----|--------|
| 0 фронт | танки | агр, soak, пробитие |
| 1 | мили DPS | бурст / приоритет-цели |
| 2 | дальние DPS | AoE адды, безопасный урон |
| 3 тыл | саппорты | хил / бафф / cleanse |

Колонки L/C/R внутри могут совпадать с крыльями рейда (Восток / Центр / Запад).

## Связь с механиками рейдов

- Два танка-агра закрывают два сектора / два танкета босса.
- Танк-пробитие бьёт в окна «хрупкость» / pierce.
- Два хила держат mass/DoT; баффер усиливает окна DPS.
- Дальний ряд чистит адд-волны, не стоя во фронт-соаках.
