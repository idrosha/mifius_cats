# Рейд 1 — Небесный Двор Мяурры

## A) Тема и лор
Дворец на облаках: Солнечные Львы судят «недостойных». **Мяурра Триумфальная** режет реальность лучами-вердиктами. Легион либо срезает Золотой Коридор (босс сильнее), либо идёт через Архивы и Башни Печатей, снимая усиления.

## B) Организация (3×4 — крылья)
| Крыло | Ориентир состава | Ответственность |
|---|---|---|
| Восток | 1 танк / 1 хил / 2 DPS | правый сектор, правый soak, правый алтарь |
| Запад | 1 танк / 1 хил / 2 DPS | левый сектор, левый soak, левый алтарь |
| Центр | 1 оффтанк / 1 хил / 2 DPS | shared HP аддов, интерапты, марки, бафф-переносы |

## C) Карта путей
```
[Вход: Облачные Врата]
         |
    [A: Двор Стражей]          ~3 мин
         |
    ★ РАЗВИЛКА 1
    /              \
[B: Золотой Коридор]   [C: Архив Вердиктов]
  короткий               длинный (+бафф Анти-вердикт)
         \              /
          [D: Мост Приговоров]   ~2 мин
                   |
            ★ РАЗВИЛКА 2
            /              \
    [E: Прямой Трон]     [F: Башни Печатей ×3]
      +2 стака боссу       сплит 3×4; снятие Печатей
            \              /
         [БОСС: Мяурра]
```

| Маршрут | Узлы | До пулла | Профиль босса |
|---|---|---|---|
| Короткий | A→B→D→E | ~12–14 мин | Hard (+2 Гордыни) |
| Смешанный | A→C→D→E | ~15–17 мин | Medium (+1) |
| Длинный | A→C→D→F | ~18–22 мин | Normal (0) |

## D) Короткий — потери
Нет Анти-вердикта; 3 Печати Гордыни активны (+урон, +луч Ф2, раньше Ф3); нет лута C/F.

## E) Длинный — плюсы
Бафф Анти-вердикт; 0 стаков; Ключи Сектора удлиняют safe-зоны в Ф3.

## F) Узлы
| Узел | Механика на 12 |
|---|---|
| A | 3 волны; Центр — shared HP Герольд; wipe если каст 100% |
| B | Гаунтлет лучей; 2 проводника |
| C | 4 одновременных канала свитков → бафф |
| D | 3 soak по крылу; пропуск = обвал |
| E | Мини-Палач; быстрый килл даёт +стак боссу |
| F | Сплит 3 комнаты ×4; провал комнаты = +Печать |

## G) Босс — 3 фазы
1. **100–70%** Тройной Суд: 3 луча / 3 соака (≥3/круг). Wipe: 2+ пропущенных соака.
2. **70–35%** Архив: 6 писцов; 3 синхро-интерапта Вердикт. Wipe: Вердикт проходит.
3. **35–0%** Затмение: ротация секторов; shared HP Тени. Wipe: 4 «Приговора» в одном секторе.

## H) Лут
Обычный: илы облачного сета, Перья Суда.  
Редметы: Солнечная Грива (pers ~5%); Кольцо Эха Вердикта (pers ~8%); Скипетр Затмения (group); Печать Снятой Гордыни (только длинный F); first-clear титул «Оправданный Двором».

## I) Вход / lock
Портал Облачные Врата. 3 попытки босса/неделя. Weekly lock босс-лута. First-clear сундук+титул.
