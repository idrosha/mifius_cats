## Как пользоваться

1. Скопировать **весь** блок одного предмета (от `Transparent PNG` до конца).
2. В конец каждого промпта можно добавить: `Align to provided empty base-body hero reference, same scale and pivot.`
3. После оверлея — отдельный thumb (§THUMB внизу).
4. **Negative** (общий, вставлять всегда):

```text
full cat body, face portrait, quadruped, chibi, facing right, front mugshot, mixed PvE+PvP finish on one item, neon cyberpunk, gun, sci-fi HUD, text, rarity gem stickers, floating badges, watermark, blurry mush, cropped piece, mirrored facing, second weapon, UI chrome
```
