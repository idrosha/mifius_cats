# Stitch-промпты — wireframe-формы (MF-106)

**Вёрстка (все):** landscape 16:9; блоки заполнены без пустот и без site-footer; один flush-уровень; без картинок в макете (арт добавит Stitch).  
**Не трогать (#119/#120):** trade_hub, battle_hub, gear/warehouse, practice lobby, practice_fight, victory_hall.  
**Уже живые (не в этом пакете):** login, hub, home, collection, heroes, codex, breeding, pvp_load, equip_cards, soon_clan, result_lose.

Копируй один блок за раз в Stitch.

---

## Мифмир (`yard`)
Горизонтальный стартовый экран PvE: слева карта из 5 подписанных узлов со статусами волн, справа список 3 волн выбранного узла и CTA «В БОЙ» / «Расстановка», снизу превью строя 3 слота (танк→боец→тыл). Без иллюстраций карты — только блоки и подписи. Бренд Мифиус, тёплый tavern hearth.

## Строй (`formation`)
Inline lineup 3v3: три колонки «свои / VS+прогресс загрузки / враги», кнопки «В бой», «К карте», «В Таверну». Не вкладка меню Бои. Плотно, без подвала.

## Бой (`battle`)
Shared fight HUD: шапка РАУНД/энергия/таймер, три зоны союзники–поле–враги, снизу рука 4 карт и кнопка «ЗАВЕРШИТЬ ХОД». Без верхнего сайт-меню в композиции формы.

## Победа (`result_win`)
Экран итога: крупно «Победа», бейдж режима, XP/лут блоками, CTA «Ещё бой» / «Расстановка» / «В Хаб». Один шаблон на режимы.

## Данжи (`boss_dungeon`)
Старт данжа: список подземелий с ключами + превью 3 волн (~6 / ~10 / босс+4) и вход в строй. Не путать с рейдом.

## Рейд / легион 12 (`boss_raid`)
Старт рейда: сетка до 12 слотов отряда, карточка босса/статуса набора, CTA «Вступить в рейд».

## PvP (`pvp`)
Арена: блок ранга/билетов/BM, блок подбора (общий кросс-плей пул), CTA поиск и расстановка. Unlock tip возможен, но форма полная.

## Зал гильдии (`guild`)
Три колонки: орден (имя/ранг/цель сезона), состав с вкладом, действия (тех/казна/бой гильдий). Зал Гильдии / Орден.

## Бой гильдий (`guild_battle`)
Lobby GvG: выбор размера 3/6/12, слоты лобби, CTA поиск / расстановка / хаб.

## Боевой пасс (`pass`)
Сезонный Пропуск «Лапы Судьбы»: таб СЕЗОН, уровень/XP/×2 ACTIVE, горизонтальный трек боксов R1–R8, «Забрать всё». Без подвала.

## Чаты ×3 (`chat_global` / `chat_guild` / `chat_friends`)
Одна компоновка: лента + поле ввода + 🎲, справа карточка игрока (имя/lvl/BM/статус). Меняется только канал (Общий Чат / гильдия / друзья).

## Таверна (`tavern`)
Барная Карта: молоко со льдом, Хрустящая Мышка и PvE-баффы; статус HP/энергии; быстрый хил. Без зелий крафтеров.

## Магазин (`shop`)
Лавка: кошелёк battle coins + сетка товаров (Ларцы, Семя Стихий, Боевой Пасс, Серая Броня, 12 котов) — ячейки с названиями, без картинок в wireframe.

## Рынок (`market`)
Инструменты (Лопата/топор/Кирка) и Семена для Двора; блок быстрой скупки лута с суммой и кошельком.

## Аукцион (`auction`)
Фильтры категорий + лента лотов игроков + табы «мои ставки/продажи» + «Выставить лот». Торги без иллюстраций.

## Рейтинг игроков / гильдий (`rating_players` / `rating_guilds`)
Таблица Лидеров Топ-100: фильтр сезона слева, ровная таблица справа. Одна компоновка на оба экрана.

## Сеты брони (`armor_sets`)
Атлас: фильтры все/есть/закрыто, список сетов, inspector с бонусами 2/4 шт. Без img.

## Классовые сеты (`class_sets`)
Сетка из 6 ролей (танк/боец/ассасин/стрелок/маг/саппорт) с местом под бонусы сета.

## Крафт (`craft`)
Список рецептов + станок (шанс/цена/Скрафтить ×1/×5). Gated tip допустим, форма заполнена.

## Двор (`soon_farm`)
Три колонки без изометрии: Анбар (ресурсы/час), узлы угодий с «Собрать», панель действий (посадить/нанять/автоферма/рынок). Никаких site-footer.
