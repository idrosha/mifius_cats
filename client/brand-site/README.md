# Мифиус — brand landing

Marketing site for **Мифиус: Мифические котики** / **Mythfel: Mythic Felines**.  
Canon **1.4.8-Web** (Tavern Hearth Battler). Not the in-game web-hud shell.

Slogan: *Очаг греет лапы, руны куют сталь*

## Run

```bash
# from repo root
python3 -m http.server 4173 --bind 127.0.0.1 --directory client/brand-site
```

Open http://127.0.0.1:4173/
